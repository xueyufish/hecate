# Spec Delta

## ADDED Requirements

### Requirement: 装配区分运行来源并完整报告授权漂移

配置了受管通道的宿主 SHALL 仍按本地授权处理独立来源运行，仅对受管运行应用受管授权 profile。宿主配置指纹 SHALL 覆盖治理规则、审批人、撤销、身份与受管策略及执行定义，且不得包含解析后的秘密值。未经期望配置门校验的历史证据上传成功 MUST NOT 清除漂移标记。已观察的明确受管身份失效 SHALL 对新受管动作生效，包括持有本地审批的动作。

#### Scenario: 受管宿主执行独立任务

- **WHEN** control_plane 已配置但运行来自合法独立入口
- **THEN** 本地 profile 正常处理该任务，缺少受管租约不改变其授权

#### Scenario: 授权配置变更后证据补传成功

- **WHEN** 本地授权配置改变，平台拒绝上报指纹，而历史证据上传成功
- **THEN** 指纹发生变化，漂移标记保持直到受门禁的请求验证成功
