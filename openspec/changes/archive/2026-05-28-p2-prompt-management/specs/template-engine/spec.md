## 新增需求

### 需求：使用变量渲染模板
系统须使用提供的变量渲染 Jinja2 模板。

#### 场景：简单变量替换
- **当** 模板包含 `{{ name }}` 且变量 = {"name": "Alice"}
- **则** 系统渲染为 "Hello Alice"

#### 场景：缺失变量
- **当** 模板包含 `{{ name }}` 但未提供 name
- **则** 系统渲染为空字符串或抛出验证错误

### 需求：模板验证
系统须在保存前验证模板。

#### 场景：有效模板
- **当** 用户保存有效的 Jinja2 模板
- **则** 系统接受它

#### 场景：无效模板语法
- **当** 用户保存带有无效 Jinja2 语法的模板
- **则** 系统返回 422 及语法错误详情

### 需求：沙箱渲染
系统须使用 Jinja2 SandboxedEnvironment 防止代码注入。

#### 场景：阻止不安全操作
- **当** 模板包含 `{{ ''.__class__.__mro__ }}`
- **则** 系统抛出 SecurityError

### 需求：变量提取
系统须自动从模板中提取变量。

#### 场景：提取变量
- **当** 模板包含 `{{ name }}` 和 `{{ age }}`
- **则** 系统提取变量 = ["name", "age"]
