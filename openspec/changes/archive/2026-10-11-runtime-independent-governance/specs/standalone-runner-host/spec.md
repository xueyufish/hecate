# Spec Delta

## ADDED Requirements

### Requirement: 派发边界接入统一受控动作服务

durable profile 的**所有**工具派发(含 readonly)SHALL 经统一受控动作应用服务完成授权判定:本地身份信封、参数摘要、副作用分类与审批引用进入同一判定路径,平台与独立宿主共用语义与测试。readonly 动作可保留差异化的台账与存储故障策略(如轻量回执),但 MUST NOT 豁免授权判定与撤销检查——本地撤销对读取同样即时生效。判定拒绝时业务 API 调用计数为零并留拒绝证据;readonly 派发的既有动作台账/对账语义不变。受管租约门(已交付)继续先于本判定,不受影响。

#### Scenario: 本地保护动作经判定后执行

- **WHEN** standalone durable 宿主派发一个写类业务动作且判定通过
- **THEN** 动作经台账领取后执行,判定与执行回执可在本地证据中关联查询

#### Scenario: readonly 工具同样经授权判定

- **WHEN** 宿主派发一个 readonly 工具,其调用主体已被本地撤销授权或不在工具级允许范围
- **THEN** 派发被判定拒绝且无业务 API 调用,拒绝留证据;判定通过的 readonly 派发沿用既有台账语义

#### Scenario: 判定拒绝零副作用

- **WHEN** 本地策略对某保护动作返回拒绝
- **THEN** 业务 API 无调用,拒绝结果与证据记录可查询,任务按失败策略处理

### Requirement: 本地审批的权威存储与签发

独立宿主 SHALL 拥有本地审批权威:仅本地信任材料中登记的审批主体(经本地授权配置获授审批权的 principal)可签发批准;审批事实(主体、参数摘要、资源、期限、一次性消费状态、撤销状态)SHALL 持久化于宿主本地 durable 存储,不依赖平台审批服务。重启后审批 SHALL 可按引用查询、按动作身份消费与撤销;一次性消费状态跨重启保持。已消费/已撤销/过期的批准 MUST NOT 授权**其他**动作;同一动作(按 `invocation_id`)在实际派发前恢复时可凭既有消费关联继续(继续前重新核验撤销、硬拒绝与期限),已完成动作只按台账回填结果。

#### Scenario: 重启后审批可查询且一次性消费保持

- **WHEN** 宿主重启后按审批引用查询,并对同一批准发起第二次消费
- **THEN** 查询返回持久化事实,其他动作的第二次消费被拒绝,业务副作用不重复

#### Scenario: 本地撤销审批后动作拒绝

- **WHEN** 审批主体在本地撤销某批准后,动作派发引用该批准
- **THEN** 动作被拒绝,拒绝关联到撤销记录,撤销前的执行事实不被改写

#### Scenario: 未登记主体签发的批准无效

- **WHEN** 一个不在本地审批主体登记中的 principal 尝试签发批准
- **THEN** 该批准不生效,不能授权任何受保护动作

### Requirement: 本地 policy profile 与业务身份 adapter

独立宿主 SHALL 支持本地 policy profile:从客户配置的本地信任材料与本地授权配置解析业务身份、工具级动作范围与审批要求,允许业务 App 的身份/权限 adapter 提供可信上下文与本地策略;不要求安装平台 IAM、组织目录或审批 UI。无平台 tenant 时使用客户配置的不可混淆部署/数据域标识;profile 与授权配置 MUST NOT 经运行期请求修改,本地撤销(移除某 principal/Agent 授权)对新派发即时生效。

#### Scenario: 无平台 IAM 的本地授权闭环

- **WHEN** 宿主仅以本地信任材料与本地授权配置运行,某 App 身份获授权的工具范围不含写类动作
- **THEN** 该身份的写类派发被本地策略拒绝,全程未依赖平台服务或平台管理表

#### Scenario: 本地撤销即时生效

- **WHEN** 运维从本地授权配置移除某 Agent principal 的工具授权
- **THEN** 该 principal 的新工具调用被拒绝,既有执行事实与证据不被改写

#### Scenario: 运行期请求不能修改作用域

- **WHEN** 已认证调用方在请求中携带试图改写部署/数据域或策略的 字段
- **THEN** 服务端忽略这些字段,作用域仍由本地配置决定

### Requirement: 独立宿主计量调用的本地预算控制

独立宿主 SHALL 对可计量调用(模型、计费工具)执行与平台一致的预算预留/结算语义,记账键为 `invocation_id`,账目落在本地存储;预算耗尽时新计量调用被拒绝并留证据,不影响已结算用量。供应商未知用量按 `estimated/unverified` 标记。

#### Scenario: 本地预算耗尽拒绝新模型调用

- **WHEN** standalone 宿主上某任务的本地预算余量耗尽
- **THEN** 新模型调用被拒绝且留证据,任务按预算停止语义处理,不静默跳过
