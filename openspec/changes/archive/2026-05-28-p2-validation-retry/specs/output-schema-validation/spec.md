## 新增需求

### 需求：根据 Schema 校验 LLM 输出
系统须根据预期的输出 schema 校验 LLM 响应。

#### 场景：有效的 JSON 输出
- **当** LLM 返回匹配 schema 的有效 JSON
- **则** 系统接受响应

#### 场景：无效的 JSON 输出
- **当** LLM 返回无效 JSON
- **则** 系统记录错误并请求带着错误上下文重试

### 需求：自动修复常见格式错误
系统须尝试自动修复常见的 LLM 输出格式错误。

#### 场景：缺少引号
- **当** LLM 返回 `{name: "Alice"}`（键缺少引号）
- **则** 系统自动修复为 `{"name": "Alice"}`

#### 场景：尾部逗号
- **当** LLM 返回 `{"name": "Alice",}`（尾部逗号）
- **则** 系统自动修复为 `{"name": "Alice"}`
