# Spec Delta — execution-approval-binding

## ADDED Requirements

### Requirement: 系统发起执行的快照归属

无人类用户的系统发起执行(如 Workflow 子任务)SHALL 以服务端已验证的 agent principal 派生确定性合成租户键持久化引擎快照——键从持久化任务载荷的 agent 归属派生,不得伪造人类用户身份,也不得从请求输入取值。恢复路径 SHALL 从同一持久事实推导同一键加载快照;键推导不一致、归属缺失或快照不可加载时,续跑按既有保守语义拒绝,不得放宽归属校验。带人类用户的执行保持现行为不变。

#### Scenario: 系统子任务的快照可持久化且可恢复

- **WHEN** 以系统身份(无 `user_id`)派发的执行在持久审批停车后经授权唤醒续跑
- **THEN** 引擎快照在停车前已按 agent principal 派生的键持久化,续跑门以同一键加载并原生续跑同一引擎会话

#### Scenario: 归属推导不一致拒绝恢复

- **WHEN** 恢复路径按与保存时不同的归属键推导尝试加载快照,或任务载荷缺失 agent 归属
- **THEN** 快照不可加载,续跑按既有保守语义拒绝,不降级为无快照重放
