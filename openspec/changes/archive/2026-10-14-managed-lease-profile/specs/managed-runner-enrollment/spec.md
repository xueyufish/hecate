# Spec Delta

## MODIFIED Requirements

### Requirement: 限时授权租约约束受管动作且断连不自授权

平台按 `security-claims` 语义签发限域限时租约(签发者、受众、部署绑定、主体、动作范围、策略版本、签发时间、期限、防重放);宿主 MUST 验证签发者、受众、部署绑定、策略版本与期限后接受新工作。断连后租约到期或超过 profile 声明的最大陈旧窗口,新受保护动作 MUST 停止;宿主 MUST NOT 切换为本地自授权或更换信任根。

profile SHALL 显式配置最大陈旧窗口(`max_staleness_seconds`)与过期后的拒绝行为,窗口为操作员受控配置,网络事件 MUST NOT 变更;离线有效期取租约 `exp` 与 `iat + max_staleness_seconds` 的较早者。租约期限与陈旧窗口判定 MUST 经可信时间校验:时钟回拨或重启后时间不可信时,依赖该期限/窗口的新动作 MUST 被拒绝,不得放宽放行。断连期间中心撤销无法即时传播,由最大陈旧窗口上界约束;需在线判定的高风险(受保护写类)动作在断连时停止,除非存在当前有效的本地审批绑定(本地审批权威签发、绑定校验通过且期限经可信时间判定)——本地审批是补位机制,不扩大租约 scope。

租约携带的策略版本 MUST 与宿主 profile 期望的策略版本一致;不一致 MUST 拒绝授权受保护动作,旧版本租约 MUST NOT 越过本地已知拒绝。

同 Run 的第二个及后续受保护动作在当前租约 nonce 已消费时,宿主 MUST 采用**有界等待续租**策略:等待通道下一次 pull 安装新租约,等待预算 SHALL 是显式声明的策略参数(声明为宿主断连/续租窗口),超窗后 MUST 转为显式证据化拒绝(执行失败、停止后续工具、零业务副作用)。等待只覆盖"新租约未到达"这一瞬态;动作范围越界、签发者/部署绑定不匹配、策略版本不匹配 MUST 立即拒绝,不等待。已决动作(账本已有确定结果)的回放 MUST NOT 消耗租约 nonce。

租约 nonce 消费记录 MUST 跨宿主进程重启保持:重启后回注已消费且未过期的旧租约 MUST 被拒绝,不得再次武装动作;`update` 在安装新租约前 MUST 拒绝已消费 nonce 的重放租约(不得替换当前租约);其余无效租约(篡改、过期、绑定不匹配)按既有语义安装,由派发边界以精确原因拒绝并留证据。

#### Scenario: 租约过期后新受保护动作停止

- **WHEN** 断连超过租约期限后宿主收到新的受保护动作请求
- **THEN** 拒绝执行且不产生本地自签授权,拒绝留证据

#### Scenario: 陈旧超窗但未到期的受保护动作拒绝

- **WHEN** 宿主断连时长超过 profile 声明的最大陈旧窗口,但最后租约的 `exp` 尚未到达,此时收到新的受保护动作请求
- **THEN** 该动作被拒绝且零业务副作用,拒绝原因标明陈旧超窗,不产生本地自签授权

#### Scenario: 策略版本不匹配的租约拒绝

- **WHEN** 平台签发的租约携带的策略版本与宿主 profile 期望版本不一致,受保护动作请求到达派发边界
- **THEN** 该租约不得授权任何受保护动作,拒绝立即发生(不进入续租等待),拒绝留证据

#### Scenario: 时钟回拨不延长受管授权

- **WHEN** 宿主时钟被回拨或重启后时间不可信,依赖租约期限/陈旧窗口判定的受保护动作请求到达
- **THEN** 时间不可信期间该动作被拒绝,受管授权不因回拨而延长;时间恢复可信后按剩余有效期判定

#### Scenario: 断连期间凭本地审批绑定执行受保护动作

- **WHEN** 宿主断连且租约已超窗,但该受保护动作存在本地审批权威签发、绑定校验通过且期限经可信时间判定仍有效的审批绑定
- **THEN** 该动作被放行执行并留判定与回执证据;同批次无有效绑定的其他受保护动作仍被拒绝

#### Scenario: 防重放拒绝旧租约

- **WHEN** 已消费或已过期的租约被重放使用
- **THEN** 宿主拒绝该租约并留拒绝记录

#### Scenario: 多写动作经续租逐一授权

- **WHEN** 同一 Run 依次执行多个受保护动作,通道按 pull 节奏持续安装新租约
- **THEN** 每个动作恰好消耗一个新租约 nonce 并恰好执行一次业务调用,业务调用计数与动作数一致,无动作因续租等待失败

#### Scenario: 停发租约后有界拒绝零副作用

- **WHEN** 通道停止 pull(失联),在途 Run 的下一个受保护动作等待续租超过声明预算
- **THEN** 该动作被显式拒绝并留证据,Run 以失败终态收敛,拒绝后不再发生任何业务调用,已执行的前序动作事实保持不变

#### Scenario: 范围越界立即拒绝不等待续租

- **WHEN** 受保护动作请求的数据域在当前租约 scope 之外
- **THEN** 立即拒绝(不进入续租等待),nonce 不被该动作消费路径回填为可用,拒绝留证据

#### Scenario: 重启后回注已消费租约被拒绝

- **WHEN** 宿主进程重启后,已消费且未过期的旧租约被回注安装
- **THEN** 该租约不得通过验证武装任何受保护动作,拒绝留证据;重启后的新 pull 安装的新租约正常可用

### Requirement: 重连重验信任后才恢复新工作

重连 SHALL 先重新验证 enrollment 仍处于准入状态、信任根未变更、撤销与期望配置,通过后才允许新受保护动作。期望配置验证 SHALL 由宿主在凭据交换或 pull 时上报自身配置指纹(runner profile 与已装载执行定义的摘要),平台与操作员在信任根上登记的期望指纹比对;不匹配时平台 MUST 拒绝投递新任务与授权新受保护工作,宿主历史证据按游标去重补传 MUST NOT 因此受阻。期望指纹为操作员受控字段,网络事件 MUST NOT 变更。重复命令经 command_id 幂等;过期审批、旧授权、迟到命令 MUST NOT 重新激活动作;未对账 Run 维持原身份/版本与待对账状态。信任根更新与退出受管模式 SHALL 仅经显式管理员流程及审计,网络重连 MUST NOT 改变调度权。

#### Scenario: 重连验证通过后恢复

- **WHEN** 宿主重连且 enrollment 准入、信任根、撤销与期望配置均验证通过
- **THEN** 宿主接受新工作,历史事件按游标去重补传完成

#### Scenario: 期望配置不匹配拒绝新工作但补传继续

- **WHEN** 宿主上报的配置指纹与操作员登记的期望指纹不一致,宿主重连
- **THEN** 平台不投递新任务、不授权新受保护动作并留拒绝原因;断连期间累积的历史事件仍按游标去重补传,不被该拒绝阻塞

#### Scenario: 重复控制命令不重复业务动作

- **WHEN** 同一命令经重连被重复投递
- **THEN** command_id 幂等,业务动作不重复执行,回执状态不二次改写

#### Scenario: 准入被撤销后重连拒绝

- **WHEN** enrollment 被操作员撤销后宿主尝试重连
- **THEN** 新工作派发停止,已留存本地事实按策略保留,不因重连恢复调度权
