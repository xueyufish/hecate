# Tutorials

End-to-end, hands-on guides that walk you through building real features with Hecate.

If you are new, start with the [Quickstart](../getting-started/quickstart.md) first.

## Available tutorials

1. **[Build Your First Agent](01-first-agent.md)** — create a configured agent, bind tools, run multi-turn sessions, and master the CLI workflow.
2. **[Knowledge Base and RAG](02-knowledge-base.md)** — upload documents, configure chunking and embedding, and let your agent answer from your own data.
3. **[MCP Tool Integration](03-mcp-integration.md)** — connect external MCP servers as tool providers, or expose Hecate itself as an MCP server.
4. **[Multi-Agent Orchestration](04-multi-agent.md)** — build workflows with six collaboration patterns (Hierarchical, Handoff, Pipeline, Broadcast, Negotiation, Debate).
5. **[Guardrails and Hooks](05-guardrails-hooks.md)** — enable built-in PII masking and injection defense, configure shell hooks, and write custom Python guardrails.

More tutorials are in progress.
