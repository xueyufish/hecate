# Contributors

Hecate is built by a community of contributors. This page recognizes the people who have made the project possible.

> **Note**: Hecate is in alpha and the contributor base is small. This page will grow as the project matures.

---

## Maintainers

The Hecate Team is the current set of maintainers. They have commit access to the main branch and are responsible for releases, security, and roadmap.

The maintainer team currently includes:

- The Hecate core contributors (listed in `git log --format='%an' | sort -u`)

As the project grows, we'll expand the maintainer team following the [OpenSpec process](../design/adr/) — important architectural decisions are made via ADR consensus, not unilateral commit access.

## All contributors

Hecate uses [GitHub's contributor graph](https://github.com/xueyufish/hecate/graphs/contributors) as the canonical list. Every commit, issue, and PR is attributed.

The full list of contributors is auto-generated and available at:

- **GitHub**: [github.com/xueyufish/hecate/graphs/contributors](https://github.com/xueyufish/hecate/graphs/contributors)
- **Git CLI**: `git shortlog -sn --all` (run from a clone of the repo)

## How to become a contributor

Contributions are not limited to code. You can contribute by:

- **Reporting bugs** — open a GitHub issue with a minimal reproduction
- **Fixing bugs** — comment on an issue, then submit a PR
- **Improving docs** — typos, unclear explanations, missing examples
- **Writing tutorials** — share what you built
- **Reviewing PRs** — comment on others' PRs
- **Answering questions** — in GitHub Discussions, Discord (when launched), or Stack Overflow
- **Sharing Hecate** — write a blog post, give a talk, mention it in a relevant conversation

See [Contributing Guide](../../CONTRIBUTING.md) for the workflow.

## Contributor License Agreement (CLA)

Hecate does **not currently require** a CLA. All contributions are accepted under the project's MIT License (the same as the codebase).

If a CLA becomes necessary in the future (e.g., for dual-licensing or re-licensing), existing contributors will be grandfathered — your prior contributions remain under MIT.
